Site Name

CourseHub

The name CourseHub was selected because it represents a central location where students can browse courses, view details, register interest, and access educational resources.

Site Purpose

The CourseHub website provides information about available educational courses. Users can browse course offerings, learn about course requirements, submit inquiries, and access course-related information through an easy-to-use interface.

Scenarios

  • What courses are currently available for enrollment?
  • How can I contact the organization for more information about a course?
  • Which courses are best for beginners?

Color Scheme

Navy Blue (#1E3A5F)

Used for headings, navigation, and important accents.

Light Gray (#F4F4F4)

Used for page backgrounds and content sections.

White (#FFFFFF)

Used for content areas and cards.

Typography

Roboto – Used for body text and general content.

Montserrat – Used for headings and navigation.
