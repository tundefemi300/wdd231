# Explore Ibadan — WDD 231 Individual Website Project

A three-page responsive tourism website about Ibadan, Nigeria.

## Main pages
- `index.html` — landing page
- `attractions.html` — 18 attractions dynamically loaded with Fetch API
- `plan.html` — visitor planning form and localStorage preferences

## Supporting pages
- `form-action.html` — form results page; does not count toward the three-page requirement
- `attributions.html` — sources/attributions

## JavaScript requirements demonstrated
- Fetch API with `async/await`
- `try...catch`
- JSON parsing
- Dynamic content generation
- 18 data records
- Multiple data properties per record
- localStorage
- accessible `<dialog>` modal
- DOM manipulation
- event listeners
- filter/map/forEach
- template literals
- ES modules
